# 파일 인텔리전스 사용 가이드

## 사용 순서

1. AI 솔루션 센터에서 업무 상황을 입력합니다.
2. **참고 파일**에서 최대 10개를 선택합니다.
3. 파일별 분류·처리 상태·구조 요약·민감정보 경고를 확인합니다.
4. 추천에 사용할 파일만 **추천에 포함** 상태로 둡니다.
5. 필요한 경우 파일별 분석 메모를 적고 **분석 시작**을 선택합니다.

파일을 추가하거나 포함 상태·메모를 바꾸더라도 이전 추천 결과는 자동으로 바뀌지 않습니다. 다시 분석해야 새 입력이 반영됩니다.

## 처리 파이프라인

`파일 선택 → 수량·용량 검사 → MIME·확장자 분류 → 실행 파일 선차단 → 유형별 로컬 Adapter → 민감정보 탐지·가림 → 안전한 요약 생성 → 사용자가 포함/제외 → 분석 시점 스냅샷` 순서입니다. 화면 컴포넌트는 원문을 직접 분석하지 않고 공통 pipeline 결과를 사용합니다.

텍스트는 내용 요약, CSV·JSON·XML은 구조 요약, 이미지·미디어는 메타데이터, PDF·Office·압축·미확인 바이너리는 사용자 설명을 사용합니다. 실행 파일은 어떤 메모나 추천 근거도 받지 않습니다.

## 분석 결과 읽기

- `분석 완료`: 제한된 범위에서 구조 또는 메타데이터를 읽었습니다.
- `설명만 제공`: 바이너리를 해석하지 않고 파일 유형과 한계를 안내합니다.
- `차단`: 실행 가능 파일이므로 읽기 전에 제외했습니다.
- `제외`: 사용자가 추천 근거에서 제외했습니다.
- `경고`: 민감정보 후보, 불규칙한 CSV 행, DOCTYPE 같은 확인 항목이 있습니다.

CSV·JSON·XML의 구조·키 이름은 업무 근거 후보일 뿐 실제 ERP/MES schema 판정이 아닙니다. 로그의 오류 후보도 장애 원인 확정이 아닙니다.

파일 하나의 해석에 실패해도 다른 파일 처리는 계속합니다. 실패 파일은 첨부 목록에 남기고 오류 또는 설명 필요 상태로 표시하며, 구조 분석 성공으로 바꾸지 않습니다. 허용 용량을 넘으면 전체 분석이라고 표현하지 않습니다.

분석을 실행한 순간 포함된 파일 요약은 결과 스냅샷이 됩니다. 이후 파일을 제외하거나 메모를 바꿔도 기존 결과는 유지되고 다음 분석부터 반영됩니다.

## 내보내기

화면 결과, Markdown, 컨설턴트 인계 요약, 검토 패키지에는 실제 파일명·전체 원문·바이너리를 넣지 않습니다. 포함 파일은 순번·유형·집계·마스킹된 요약으로만 표시됩니다.

브라우저를 새로 고치면 선택 파일과 메모는 사라집니다. 서버 저장·고객 시스템 전송·DB 저장은 하지 않습니다.

## Adapter 확장 기준

향후 후보는 `PdfTextAdapter`, `OfficeDocumentAdapter`, `SpeechToTextAdapter`, `VisionAnalysisAdapter`, `ApprovedRemoteAiAdapter`입니다. 모두 현재는 미구현입니다. 새 Adapter는 공통 제한, 실행 금지, 원문 미보관, 결정적 결과 순서, 마스킹, Object URL 정리, 외부 요청 0 계약을 통과해야 합니다. 외부 AI Adapter는 회사 승인과 전송 정책이 확정되기 전에는 연결하지 않습니다.
