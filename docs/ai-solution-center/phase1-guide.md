# AI 솔루션 센터 기본 PoC (관문 12-1)

## 현재 구현 기능

- **컨설턴트 파일 분석**: 파일명·확장자·크기 목록과 공통 상황 설명을 바탕으로 로컬 기본 가이드를 만듭니다.
- **고객 업무 Q&A**: 문의, 현재 관리 방식, 원하는 기준, 현장 제약을 정리해 검토 가이드를 제공합니다.
- **결과 항목**: 입력 요약, 추정 업무영역, 주요 문제, 기본 권고안, 단계적 적용, 우선순위, 추가 확인정보, 위험·주의사항, 확인 질문, 신뢰도, 내부·외부 검토 필요 여부를 표시합니다.
- **보안 경계**: 서버 업로드·외부 AI 호출·고객 데이터 저장 없이 브라우저 메모리에서만 동작합니다.

## 실제 지원 파일과 처리 방식

자동 텍스트 읽기는 `.txt`, `.md`, `.csv`, `.json`, `.xml`, `.log` 및 MIME `text/*` 파일에만 적용합니다. 파일 크기는 **512KB 이하**만 자동으로 읽습니다.

PDF, Word, Excel, PowerPoint, 이미지, 음성, 영상 등 지원하지 않는 파일은 목록에 유지하지만 내용을 자동 추출하지 않습니다. 사용자는 공통 상황 설명에 핵심 내용이나 요약을 직접 입력해 가이드를 받을 수 있습니다. 이 PoC는 파일 업로드나 서버 저장을 수행하지 않습니다.

## 로컬 규칙 엔진

결과는 외부 모델을 호출하지 않는 결정적 로컬 규칙 엔진으로 생성합니다. 같은 입력과 업무영역에는 같은 결과가 나옵니다. 현재 지식 템플릿은 다음 네 가지입니다.

1. 통합형 LOT·추적성 관리
2. 현장 입력 최소화
3. 중요 공정 중심 추적
4. 부서간 관리기준 정렬

출력은 회사의 확정 규칙이 아닌 기본 검토 가이드입니다. 정보가 충분하지 않으면 신뢰도를 낮추고 최대 세 개의 확인 질문을 제시합니다.

## 회사 지식 삽입 지점

`src/features/ai-solution-center/solutionKnowledge.ts`의 지식 항목에 회사가 승인한 업무 정의, 품목별 추적 수준, 공정·검사 기준, 책임 체계를 추가합니다. 실제 운영 기준은 업무 담당자와 보안 검토를 거친 뒤에만 반영합니다.

## 확장 순서

1. 회사 ERP·MES 지식 반영
2. PDF·Office 문서 파싱
3. 음성 STT
4. 이미지·영상 처리
5. 보안 검토를 마친 외부 LLM 연결
6. 컨설턴트 피드백 반영
7. 고객 FAQ와 대화 이력 관리
