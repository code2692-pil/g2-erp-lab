# ERP/MES 실전 시나리오 라이브러리 가이드

## 목적

시나리오 라이브러리는 빈 입력에서 시작하는 사용자가 대표 문제의 질문 구조를 빠르게 이해하도록 돕는 PoC 예시입니다. 시나리오를 적용해도 추천이나 업무 결정을 자동 실행하지 않습니다.

## 제공 시나리오

1. 공급업체 LOT와 사내 LOT 연결
2. 시리얼 관리 시작 시점
3. 생산팀 입력 부담
4. 검사 부적합·재작업
5. 창고·재고 위치 관리
6. 수주·작업지시 연결
7. 포장·출하 추적성
8. 설비 이상·생산 영향
9. 기준정보 중복
10. 긴급 작업지시

각 시나리오는 stable id, 제목, 분류, 문제, 권장 탭, 문의·현재 방식·희망 기준·현장 제약, 관련 부서, 업무 영역, 우선순위, 기대 지식 분류를 가집니다. 세부 내용은 큰 탭 대신 카드형 목록으로 제공합니다.

## 적용 규칙

- 기존 입력이 비어 있으면 선택한 시나리오를 입력 칸에 채웁니다.
- 기존 입력이 있으면 공통 확인 창으로 덮어쓰기 여부를 묻습니다.
- 취소하면 현재 입력을 그대로 유지합니다.
- 적용 후에도 **분석 시작**을 직접 선택해야 합니다.
- 시나리오는 업무 판단의 출발점이며 실제 고객사 기준·책임자 승인·현장 확인을 대신하지 않습니다.

## 회사 지식과의 차이

시나리오는 질문을 시작하기 위한 일반 입력 예시입니다. 회사 지식팩은 승인된 사내 기준의 근거 후보입니다. 어느 쪽도 회사의 확정 업무 규칙이나 자동 적용 지시가 아니며 결과에는 컨설턴트·개발·현장 검토가 필요합니다.

## 새 시나리오 추가 기준

`solutionScenarios.ts`에 중복되지 않는 stable id와 필수 입력을 추가하고, 기존 입력 교체 확인·자동 분석 금지·관련 부서/우선순위 반영을 유지합니다. E2E에서는 카드 표시, Confirm의 적용/취소, 입력 값, 분석 전 결과 없음, 사용자가 분석한 뒤 선택 시나리오·대안·로드맵 표시를 검증합니다.
