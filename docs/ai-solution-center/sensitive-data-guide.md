# 민감정보 보호 가이드

## 자동 탐지 범위

다음 문자열 후보를 입력·파일 요약·추천 근거·Markdown·인계 요약·검토 패키지에서 마스킹합니다.

- 이메일, 한국 전화번호, IP 주소
- 주민등록번호 형식 후보, 카드번호 형식 후보
- URL query의 token·key·secret·password 계열 값
- password, access token, refresh token, API key, secret 할당값
- Bearer token, AWS access key 형식, 긴 영숫자 token 후보

탐지 결과는 `낮음·중간·높음` 신뢰도와 위험 수준을 함께 안내합니다. 문맥을 완전히 이해하는 DLP가 아니므로 오탐과 누락이 있을 수 있습니다.

가림 표시는 category별로 일관되게 이메일 `a***@example.com`, 전화번호 `010-****-1234`, IP `192.168.*.*`, token `[REDACTED_TOKEN]`, 주민등록번호 후보 `******-*******`, 카드번호 후보 `****-****-****-1234` 형태를 사용합니다. 원문 값은 console·오류 메시지·화면 근거·Markdown·인계 요약·검토 패키지에 기록하지 않습니다.

## 사용자가 지켜야 할 기준

- 실제 비밀번호·API key·고객 개인정보·주민번호·카드번호를 입력하지 않습니다.
- 운영 로그를 그대로 넣지 말고 필요한 구간만 익명화합니다.
- 파일명에도 고객명·사번·계약번호 같은 식별자를 쓰지 않는 것이 안전합니다.
- 마스킹된 결과도 외부 전달 전 담당자가 다시 검토합니다.
- 외부 AI 연결 전 보안·법무·고객 데이터 처리 승인과 전송 항목 검토를 완료합니다.

## 보안 경계

파일 분석은 브라우저 메모리에서 수행하며 외부 네트워크로 전송하지 않습니다. 실행 파일은 확장자 분류 직후, 본문 읽기 전에 차단합니다. XML의 외부 entity를 가져오거나 스크립트를 실행하지 않고, JSON 객체를 다른 객체에 병합하지 않습니다.

이 기능은 회사 DLP, 백신, 악성코드 분석, 접근권한, 감사로그, 암호화 저장을 대체하지 않습니다. 운영 적용 시 역할별 권한, 보존기간, 다운로드 감사, DLP, Secret scanner가 별도로 필요합니다.
