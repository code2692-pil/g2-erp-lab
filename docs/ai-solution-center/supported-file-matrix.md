# AI 솔루션 센터 지원 파일 매트릭스

## 처리 기준

모든 처리는 브라우저 안에서만 수행합니다. 서버 업로드, 외부 OCR, 외부 미디어 변환, 압축 해제, 매크로 실행은 하지 않습니다.

| 유형 | 첨부 | 본문 추출 | 구조 분석 | 메타정보 | 사용자 설명 | 민감정보 가림 | 현재 한계 | 향후 확장 방식 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| TXT·Markdown·LOG | 가능 | 앞부분만 | Markdown/LOG 규칙 | 크기·형식 | 선택 | 가능 | 최대 512KB, 의미·원인 확정 안 함 | 승인된 텍스트 Adapter 보강 |
| CSV | 가능 | 미리보기만 | 현재 실제 지원 | 크기·형식 | 선택 | 가능 | 최대 2MB, 모든 dialect 보장 안 함 | 검증된 CsvAdapter |
| JSON | 가능 | 경로 요약만 | 현재 실제 지원 | 크기·형식 | 선택 | 가능 | 최대 2MB, key 최대 30개 | schema 검증 Adapter |
| XML | 가능 | 경로 요약만 | 현재 실제 지원 | 크기·형식 | 선택 | 가능 | 최대 2MB, 외부 entity 미지원 | 승인된 XmlAdapter |
| 이미지 | 가능 | 없음 | 없음 | 크기·가로·세로 | 가능 | 메모에 적용 | OCR·장면 분석 없음 | `VisionAnalysisAdapter` |
| 오디오·비디오 | 가능 | 없음 | 없음 | 재생시간·화면 크기 시도 | 가능 | 메모에 적용 | codec에 따라 실패, STT·장면 분석 없음 | `SpeechToTextAdapter`, `VisionAnalysisAdapter` |
| PDF | 가능 | 없음 | 없음 | 크기·형식 | 필요 | 메모에 적용 | 본문 파싱 없음 | `PdfTextAdapter` |
| Word·Excel·PowerPoint | 가능 | 없음 | 없음 | 크기·형식 | 필요 | 메모에 적용 | 문서·시트·슬라이드 파싱 없음 | `OfficeDocumentAdapter` |
| 압축 | 가능 | 없음 | 없음 | 크기·형식 | 필요 | 메모에 적용 | 압축 해제 안 함 | 별도 보안 승인 후 전용 Adapter |
| 실행 파일 | 표시만 | 없음 | 없음 | 확장자 분류 | 불가 | 해당 없음 | 보안상 읽기 전 `BLOCKED` | 지원 예정 없음 |
| 미확인 바이너리 | 가능 | 없음 | 없음 | 크기·형식 | 필요 | 메모에 적용 | 자동 해석 없음 | 승인된 유형별 Adapter |

## 제한

- 최대 파일 수: 10개
- 파일 한 개: 50MB 이하
- 선택 파일 총합: 100MB 이하
- 텍스트 계열 분석 범위: 앞부분 최대 512KB
- CSV·JSON·XML 구조 분석 범위: 앞부분 최대 2MB

제한을 넘은 파일은 원문 전체를 읽거나 결과·내보내기·검토 패키지에 넣지 않습니다. 분석 성공은 파일 내용이 정확하거나 업무 원인이 확정됐다는 뜻이 아닙니다.

외부 AI를 연결하는 `ApprovedRemoteAiAdapter`는 현재 구현하지 않았습니다. 향후 사용하려면 회사 보안 승인, 전송 범위, 저장 정책, 마스킹 재검증이 선행돼야 합니다.
