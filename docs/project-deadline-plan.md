# 프로젝트 마감 유지보수 계획

## 기준 시각

- 유지보수 정책 시작: Gate 10
- 동결 시각: 2026-07-31 15:00 (Asia/Seoul)
- 동결 이후 허용 범위: 신호 수집과 보고서 생성

## 마감 전

1. Green 후보만 최대 10개까지 수집합니다.
2. 한 번에 사전개발 가능한 후보는 최대 2개이며, 사용자 결정 전에는 코드 수정하지 않습니다.
3. Yellow 후보는 영향 범위와 검증 비용을 보고서에만 남깁니다.
4. Red 후보는 차단 사유와 업무 결정 필요 여부만 기록합니다.

## 동결 후

- 코드 변경, 사전개발 브랜치, merge, 배포를 시작하지 않습니다.
- 현 상태, 테스트 가능 여부, TODO/FIXME, 진단 흔적을 다시 수집합니다.
- 보고서의 `finalDecision`은 빈 값으로 유지해 사람이 최종 판단합니다.
