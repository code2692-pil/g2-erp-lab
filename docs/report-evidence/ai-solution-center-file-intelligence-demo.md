# 관문 12-7 시연 절차

## 준비

`pnpm run dev:mock`으로 실행하고 AI 솔루션 센터를 엽니다. 실제 개인정보나 회사 기밀이 없는 데모 파일만 사용합니다.

## 4~5분 시연

1. **파일 선택 또는 추가**를 눌러 quoted comma가 있는 CSV를 선택하고 열·행·LOT Header 구조 요약을 확인합니다.
2. 같은 버튼으로 오류 레벨과 데모 token 후보가 있는 LOG를 추가해 오류 후보·민감정보 가림 경고를 확인합니다.
3. 소형 PNG를 추가하고 가로·세로와 OCR 미지원 안내를 확인한 뒤 파일 메모를 입력합니다.
4. LOG의 **분석에 포함**을 껐다 켜며 목록 유지와 제외 상태를 확인합니다.
5. **ERP·MES 업무 예시**를 펼쳐 **검사 부적합·재작업**의 **이 예시로 입력**을 누르고, 기존 입력이 있으면 공통 확인 창에서 **적용**을 누릅니다.
6. 자동 결과가 생기지 않는 것을 확인하고 **기본 가이드 요청**을 눌러 추천·대안 비교·3단계 로드맵을 확인합니다.
7. 결과의 파일 처리·가림 안내와 **컨설턴트 인계 요약**을 확인합니다.
8. 검토 상태·역할·체크리스트를 입력하고 **검토 상태 기록**, **검토 패키지 다운로드**를 차례로 누릅니다.
9. 다운로드 JSON에 실제 파일명·전체 원문·token 후보가 없고 schema 1.1인지 확인합니다.
10. **검토 패키지 불러오기**에서 기존 `review-package-sample.json` 1.0을 선택해 하위 호환을 확인합니다.

## 기대 결과

파일 선택과 시나리오 적용은 기존 결과를 자동 갱신하지 않습니다. 실행 파일은 읽기 전 차단되며 포함할 수 없습니다. 다운로드 이름에는 고객명·파일명·질문 내용이 들어가지 않습니다.
