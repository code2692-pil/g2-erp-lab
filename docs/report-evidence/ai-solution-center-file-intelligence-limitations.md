# 관문 12-7 한계와 후속 검토

## 현재 한계

- 브라우저 메모리 기반 PoC이며 사용자 인증·권한·DB 저장·감사로그가 없습니다.
- PDF·Word·Excel·PowerPoint 본문, 압축 내부, 이미지 OCR, 음성 전사, 영상 장면을 추출하지 않습니다.
- 미디어 메타데이터는 브라우저 codec 지원에 따라 실패할 수 있습니다.
- 파일 앞부분만 제한적으로 분석하므로 뒤쪽 내용은 반영되지 않을 수 있습니다.
- 민감정보 탐지는 정규식 기반 보조 기능이며 DLP·백신·악성코드 검사를 대체하지 않습니다.
- CSV·JSON·XML 구조와 로그 패턴은 업무 원인이나 실제 ERP/MES schema를 확정하지 않습니다.
- 시나리오와 추천은 실제 적용·승인·계획 변경·고객 통보를 수행하지 않습니다.

## 회사 적용 전 필요 사항

보안 책임자의 파일 취급 기준, 허용 확장자 정책, DLP·백신 연계, 암호화·보존기간, 역할 기반 권한, 감사로그, 실제 parser의 공급망 검토, 대용량 처리 정책, 고객사별 업무 규칙과 책임 승인 절차가 별도로 필요합니다.

## 이번 관문에서 제외한 항목

Backend/API/DTO/DB/SQL 변경, 새 외부 dependency, OCR·LLM 외부 전송, 운영 배포, PR·push·merge는 범위에 포함하지 않습니다.
