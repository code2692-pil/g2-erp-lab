# 3분 최종 시연 스크립트

## 0:00~0:30 — 공통 흐름

1. 수주등록 화면에서 **조회**를 누른다.
2. Header 행을 눌러 상세 Grid가 함께 바뀌는 것을 보여 준다.
3. 거래처 찾기 창을 열고 한 항목을 선택한다.
4. Grid 셀에서 Enter·Tab으로 다음 입력 칸으로 이동한다.

## 0:30~1:20 — 입력 보호와 오류 안내

1. 수주 상세에 값을 고친 뒤 **조회** 또는 Header 행을 누른다.
2. 변경사항 확인 창에서 **계속 편집**을 선택해 입력이 유지되는 것을 보인다.
3. 다시 실행해 **변경 폐기**를 선택하고 대상 동작이 한 번만 실행되는 것을 보인다.
4. 신규 문서에서 필수값을 비운 채 저장해 오류 요약과 오류 셀을 확인한다.
5. 첫 오류 칸으로 이동해 값을 고치고 오류 표시가 사라지는 것을 보인다.

## 1:20~2:10 — 발주·작업지시

1. 발주등록에서 신규를 누르고 품목 찾기 창과 창고 찾기 창을 사용한다.
2. 작업지시등록에서 문서를 선택하고 품목·생산라인 찾기 창, 공정·설비 찾기 창을 사용한다.
3. 공정상세에 행을 추가하고 Excel 형식 값을 붙여넣는다.
4. 저장 중에는 버튼이 비활성화되어 중복 실행되지 않음을 확인한다.

## 2:10~3:00 — 비동기 안전성과 유지보수 근거

1. 수주 조회 조건을 빠르게 바꿔도 가장 마지막 조회 결과만 남는다고 설명한다.
2. 자동 유지보수 보고서 파일의 후보 목록을 열어, AI가 바로 수정하거나 결정을 내리지 않는다고 설명한다.
3. `final-readiness-summary.md`와 `final-test-matrix.md`를 열어 PoC에서 검증된 범위와 운영 환경 미검증 범위를 구분해 보인다.

## 시연 종료 화면

`docs/report-evidence/final-readiness-summary.md`와 `docs/report-evidence/final-maintenance-candidates.md`를 나란히 보여 준다. 화면에 실제로 없는 기능은 시연 가능하다고 주장하지 않는다.
