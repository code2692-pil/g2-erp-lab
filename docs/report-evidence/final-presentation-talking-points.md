# 발표용 말하기 자료

## 시작 문장

“회사 업무 흐름을 개발환경에서 어디까지 직접 구현하고 검증할 수 있는지 확인하기 위해, 수주·발주·작업지시와 AI 보조 기능을 하나의 PoC로 구성했습니다.”

## 강조할 핵심

- 수주·발주·작업지시의 버튼, Grid, validation, 미저장 변경 보호를 같은 방식으로 정리했다.
- PC·모바일·PDA는 같은 수주 API와 데이터 구조를 사용하도록 검증했다.
- AI 솔루션 센터는 외부 AI가 ERP를 자동 완성하는 기능이 아니라, 로컬 입력·파일을 근거로 사람이 검토할 선택지를 정리하는 PoC다.
- 자동 유지보수도 코드 자동 적용이 아니라 위험을 분류하고 사람이 판단하도록 막아 둔 구조다.

## 과장하지 않는 표현

- “개발환경에서 동작 범위를 확인했습니다.”
- “로컬 SQL Server 테스트 DB에서만 CRUD 교차 검증했습니다.”
- “실제 회사 코드와 운영 데이터에는 적용하지 않았습니다.”
- “운영 적용 전에는 회사 규칙 UAT, 권한, 성능, 보안, 실제 연동 검증이 필요합니다.”

## 피해야 할 표현

- “AI가 ERP를 완성했다.”
- “운영 적용이 완료됐다.”
- “고객 환경에서 검증됐다.”
- “모든 파일을 자동 분석한다.”
- “모바일 앱/PDA 장비 연동이 끝났다.”

## 마무리 문장

“이번 결과는 기능을 계속 늘리기보다, 지금 구현한 흐름을 같은 기준으로 검토할 수 있게 고정한 릴리스 후보입니다. 다음 단계는 보고서의 후보 중 하나만 선택해 회사 기준으로 검증하는 것입니다.”
